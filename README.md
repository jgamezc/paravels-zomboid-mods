# Paravel's Project Zomboid mods

Mods for Project Zomboid Build 42 (42.21 or later) by Paravel. They share one
theme, picked once in the game's Mods options, and restyle the game's windows.

| Mod | What it does | Workshop |
| --- | --- | --- |
| [Paravel's UI](framework) (`ParavelsUI`) | The shared theme and the drawing and controls the other mods are built from. Does nothing on its own. | [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3828626636) |
| [Paravel's Enhanced Inventory](inventory) (`ParavelsEnhancedInventory`) | A grid view for the inventory and loot windows, with colour-coded item families, a tab for everything nearby and themes. | [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3828627678) |
| [Paravel's Enhanced Context Menu](contextmenu) (`ParavelsEnhancedContextMenu`) | Gives the game's right-click menus the look of Paravel's UI. | [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3828635605) |
| [Paravel's Enhanced Tooltips](tooltips) (`ParavelsEnhancedTooltips`) | Gives the game's tooltips, the ones of items included, the look of Paravel's UI. | [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3828637320) |

Paravel's UI is the shared dependency: the other three require it. Each of
them works without the others.

## Install

Subscribe on the Steam Workshop to the mods you want and to Paravel's UI, then
enable them in the game's Mods screen.

## Releases

Each Workshop release is one commit on `main`. A mod's version is tagged as
`<modId>-v<version>`, for example `ParavelsUI-v1.4.0`.

## Issues

Bug reports and suggestions are welcome as GitHub issues. Please start the
title with the mod's name, for example `[Enhanced Inventory]`, and say your
game version.
